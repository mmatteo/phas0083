# PHAS0083, Statistical Analysis of Data: the scripts

The Python scripts printed in the lecture notes of PHAS0083 - Statistical Analysis of Data taught by Matteo Agostini at University College London. The scripts are sorted by chapter and named after the example number of the notes. Each script starts with 4 lines that do not appear in the notes, which are used to import `preamble.py` assuming the entire repository has been downloaded. I recommend you keep updating the repository as the scripts of the chapters which have not been released yet might change.

## Running a script

Download or clone the whole repository, then

    pip install -r requirements.txt
    python ch09/example_9.2.2.py

Alternatively, to run a script on its own, copy `preamble.py` beside it, or replace its three import lines with the content of `preamble.py`.
